# ML Restaurants Survival Classification

ML1 2026 Task 1 project focused on predicting restaurant survival using supervised learning.

## Contents
- `restaurant_survival_exploration.ipynb`: exploratory data analysis and feature review
- `restaurant_survival_final.ipynb`: final modeling workflow
- `restaurant_survival_full.ipynb`: full project notebook version
- `restaurants_train.csv`, `restaurants_test.csv`: training and test datasets
- `submission.csv`, `submission_latest.csv`: submission outputs
- `presentation_script.md`: presentation notes

## How To Run
1. Open the notebooks in Jupyter.
2. Run cells top-to-bottom.
3. Ensure the expected CSV files are in the project root.
